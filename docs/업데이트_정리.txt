■ 웹앱

[1. 북마크 카드 (#55)]
- 마이페이지의 메모 카드 아래에 🔖 북마크 카드가 생겼습니다.
- 입력창에 링크를 붙여넣고 Enter(또는 이동) 를 누르면 새 탭으로 열리면서 목록에 저장됩니다. 저장은 열지 않고 목록에만 저장합니다.
- 입력 정리(bookmarks.js):
  - example.com처럼 https://가 없으면 자동으로 붙입니다.
  - javascript:, data: 같은 http(s)가 아닌 주소는 막고 안내 문구를 보여 줍니다.
  - 같은 주소(끝의 /, # 부분은 무시)는 중복 저장하지 않고 열기만 합니다.
- 목록: 사이트 아이콘, 이름(없으면 도메인), 누르면 이동, ✕ 삭제. 사이트 아이콘은 구글의 파비콘 서비스 주소를 이미지로 불러옵니다.
- 저장: localStorage + 기존 클라우드 동기화(bookmarks, bookmarkNextId). 기기 두 대에서 동시에 추가해도 둘 다 남도록 state-merge.js에 병합 규칙을 넣었습니다.
- 제목 자동 가져오기는 넣지 않았습니다(다른 사이트 HTML을 브라우저가 직접 읽을 수 없어 서버 API가 필요해지기 때문).

[2. 제목 편집 (#56)]
- 항목의 ✎ 버튼으로 제목을 그 자리에서 고칩니다. Enter 저장 · Esc 취소 · 입력칸 밖을 누르면 저장.
- 제목을 비우면 도메인 이름이 대신 표시됩니다. ✎를 눌러도 링크는 열리지 않습니다.

[3. 폴더 (#57)]
- 입력창 아래 칩: 전체 · 📁 폴더들 · 미분류 · + 폴더 (각 칩에 개수 표시).
- 폴더를 선택한 상태에서 링크를 저장하면 그 폴더에 들어갑니다. 각 북마크의 📁 버튼으로 다른 폴더로 옮깁니다.
- 폴더를 선택하면 이름 수정 · 폴더 삭제가 나타납니다. 폴더를 지워도 안의 북마크는 미분류로 옮겨질 뿐 지워지지 않습니다.
- 동기화: bookmarkFolders, bookmarkFolderNextId 추가.
  - 다른 기기에서 지운 폴더의 북마크는 미분류로 보입니다.
  - 두 기기에서 같은 번호로 폴더를 따로 만들면 둘 다 남기고, 각 기기의 북마크가 자기 폴더를 따라갑니다.

[4. 윈도우 98 테마를 모바일에도 적용 (#58)]
- 원인: 98 스킨 CSS 전체가 @media (min-width: 900px) 안에 있어 PC에서만 적용됐고, 🖥️ 전환 버튼도 PC에서만 보였습니다.
- 너비 제한을 없애 핸드폰에서도 적용되고, 🖥️ 버튼도 모바일에서 보입니다. (처음 쓰는 기기는 98이 기본값)
- 함께 고친 것: 모바일 헤더 오른쪽의 어두운 줄, 오늘이면서 선택된 날짜 숫자가 흰색이라 안 보이던 문제(PC 포함).

[5. 모바일 헤더와 루틴 행 (#59)]
- 파란 '나의 하루' 막대가 알림 버튼에 붙거나 겹치지 않도록 폭을 줄였습니다.
- 오늘의 일정의 루틴 행: 체크 칸을 좁히고 제목·메모 줄바꿈을 허용했으며, 체크리스트 항목은 가로로 꽉 차는 버튼 대신 줄바꿈되는 작은 항목(98 스킨은 평평한 체크박스 줄)으로 바꿨습니다.

[6. 오늘의 일정 할일 완료 체크 (#62)]
- 문제: 하루 패널의 할일 행은 완료 여부를 전혀 보여 주지 않아, 완료해도 아무것도 안 바뀌어 헷갈렸습니다(루틴 행에만 체크와 취소선이 있었음).
- 각 할일 행 오른쪽에 완료 체크가 생겼습니다. 완료하면 칠해진 ✓(98 스킨은 ✓ 체크박스), 제목 취소선, 행이 흐려집니다.
- 체크를 누르면 상세 화면을 열지 않고 바로 완료/취소됩니다. 행의 다른 곳을 누르면 예전처럼 상세가 열립니다. 기존 › 화살표는 체크로 바뀌었습니다.
- 폰에서도 같은 패널이라 똑같이 적용됩니다.

[7. 북마크 목록/그리드 보기 (#63)]
- 폴더 칩 줄 오른쪽에 ☰ 목록 / ▦ 그리드 전환 버튼이 생겼습니다.
- 그리드는 타일로 보여 줍니다: 아이콘(못 불러오면 제목 첫 글자), 제목(두 줄까지), 도메인, 전체 보기에서는 폴더 이름. 타일 위쪽의 📁 이동 · ✎ 제목 수정 · ✕ 삭제는 목록과 같고, 타일을 누르면 바로 열립니다.
- 열 개수는 화면 폭에 맞춰 자동으로 바뀝니다(폰 3열).
- 고른 보기는 이 기기의 localStorage에만 저장하고 동기화하지 않습니다.
- 함께 고친 것: 98 스킨에서 선택된 폴더 칩이 구분되지 않던 문제.

[8. 바탕화면 스킨 (PC) (#64, #67, #68, #69)]
- 🖥️ 버튼이 [윈도우 98 → 바탕화면(PC만) → 클래식] 순서로 바뀝니다. 바탕화면 스킨은 98 스킨 위에 얹은 것이라 기존 98 모양은 그대로입니다. 폰에서도 고를 수 있습니다(#75, 아래 [14]). 기본값은 계속 윈도우 98입니다.
- 청록 바탕화면 + 왼쪽 앱 아이콘. 아이콘을 누르면 해당 화면이 창으로 열립니다.
  - 아이콘 순서(#67): 달력 → 가계부 → 북마크 → 메모 → 마이페이지 (5개). 처음에는 북마크·메모가 마이페이지 창의 카드를 펼치는 방식이었으나 이후 PC에서는 전용 창으로 바뀌었습니다([11], [12]). 시작 메뉴도 같은 순서.
- 창은 한 번에 하나. 제목 막대에 지금 화면 이름과 _ □ ✕ (최소화 · 최대화/되돌리기 · 닫기). 닫으면 바탕화면만 남고 아이콘으로 다시 엽니다.
- 작업표시줄: 시작 메뉴, 열린 창 버튼(누르면 최소화/복원), 시계. 기존 알림·검색·테마·스킨 단추와 달성률은 오른쪽 트레이로 옮겼습니다.
- 맨 위 요약 막대(#68, #69): 창 위의 흰 막대 한 줄.
  예) ▸ 10월 13일 화요일 … 오늘 할일 1/3 완료 … 루틴 0/1 완료 … 오늘 가계부 지출 -12,500원 (2건) … 10월 달성률 33% (1/3) … 이번 주 구독 결제 예정 2건 31,900원 (Netflix 15일, 유튜브 프리미엄 17일)
  - 오늘 가계부 지출: 오늘 가계부의 지출 합계와 건수(수입·구독 결제 제외). 없으면 "없음".
  - 달성률: 달력이 어느 달을 보든 오늘 기준 이번 달.
  - 이번 주 구독 결제 예정: 오늘부터 토요일까지 남은 결제(멈춘 구독 제외, 한 주가 두 달에 걸쳐도 포함). 3건까지 이름과 날짜, 넘으면 "외 N건". 없으면 "없음".
  - 일정·루틴을 완료하면 바로 바뀌고 30초마다 새로 계산합니다. 글이 막대보다 길면 천천히 흘러가고(마우스를 올리면 멈춤), 최대화하면 숨습니다.
- 바탕화면 스킨이 아닐 때(98·클래식)는 이 요소들이 모두 숨겨집니다.

[9. 가계부: PC 날짜별 달력 + 카드 순서 (#65, #66)]
- 가계부 화면 카드 순서가 가계부 → 구독 → 자산으로 바뀌었습니다(PC·폰 공통, 카드 내용은 그대로).
- PC(900px 이상)에서만 가계부 화면 맨 위에 날짜별 달력 패널이 생겼습니다. 폰과 APK는 그대로입니다.
  - 왼쪽 월 달력: 각 날짜 칸에 그날 지출(구독 결제 포함, 빨강)과 수입(초록) 합계. 위에 이번 달 수입·지출·차액, 오늘 버튼. 월 이동은 아래 가계부 카드와 같은 달을 써서 함께 바뀝니다.
  - 오른쪽 상세: 날짜를 누르면 그날 지출·수입 합계와 항목(산 것·카테고리·통장), 구독 결제, 이체(합계 제외). 항목 수정·삭제, "이 날 수입/지출 추가"(날짜 자동 입력).
  - 클래식·윈도우 98·바탕화면 스킨 모두에서 보입니다.
- 세로 확대(#66): 패널 높이를 화면 높이에 맞추고(최소 560px) 달력 줄이 남는 높이를 나눠 가져 칸이 커졌습니다(1280×800에서 칸 높이 약 64 → 87px, 1920×1080에서 142px). 가계부 화면이 세로로 쌓는 구조라 달에 따라 패널 높이가 줄던 문제(6주 달에서 334px)도 고정했습니다.

[10. 바탕화면 위젯 (#70)]
- 창을 최소화하거나 닫으면 바탕화면에 작은 98 창 3개가 뜹니다(창이 열려 있는 동안은 창에 가려 보이지 않음).
  - 오늘: 오늘 할 일과 루틴. 체크 칸을 눌러 바로 완료/취소할 수 있고, 위 요약 막대도 같이 바뀝니다.
  - 이번 달 가계부: 오늘 지출, 이번 달 지출·수입·차액, 많이 쓴 곳 3개.
  - 달성·구독: 이번 달 할 일 달성률 막대, 이번 주 구독 결제 예정.
- 각 창 제목 줄의 단추(열기/통계)로 해당 화면을 엽니다. 통계 단추는 가계부를 열고 통계 카드를 펼쳐 그 위치로 스크롤합니다([13]).

[11. PC 메모장 앱 (#71)]
- PC 바탕화면 스킨에서 메모 아이콘·시작 메뉴 "메모"가 마이페이지 카드 대신 전용 메모장 창을 엽니다. 폰·클래식 스킨은 기존 메모 카드 그대로입니다.
- 왼쪽 목록: 첫 줄이 제목, 한 줄 미리보기와 날짜. 고정한 메모가 맨 위, 나머지는 최근에 고친 순.
- 검색: 내용 전체에서 찾고 찾은 글자를 노란색으로 강조. 여러 메모를 탭으로 열어 두고 전환(탭마다 ✕).
- 입력하면 0.4초 뒤 자동 저장. 상태줄에 글자 수·줄 수·저장 시각. 📌 고정, 🗑️ 지우기(내용이 있으면 확인), 아무것도 안 쓴 빈 메모는 자동 정리.
- 메모에 수정 시각(updated)과 고정(pinned)이 새로 기록됩니다. 기존 메모({id, content, date})와 호환되고 동기화도 같은 방식입니다.
- 메모 내용은 HTML로 해석하지 않고 글자 그대로 보입니다(<b> 같은 글자도 그대로 표시).
- 독립 메모는 할 일·루틴에 적는 메모와 별개입니다. 독립 메모는 전체 상태의 memos 목록, 할 일·루틴 메모는 각 항목(items, routines)의 memo 칸에 저장되고, 둘 다 Supabase의 app_state에 한 덩어리로 올라갑니다. 메모장에서 할 일 메모를 검색하는 연동은 만들지 않았습니다.

[12. PC 북마크 앱 (#73)]
- PC 바탕화면 스킨에서 북마크 아이콘·시작 메뉴 "북마크"가 전용 북마크 창을 엽니다. 폰·클래식은 기존 카드 그대로입니다.

- 북마크를 끌어서 왼쪽 폴더에 놓으면 이동. 제목 수정·삭제·폴더 이동은 기존 기능을 그대로 씁니다. 아래 상태줄에 개수와 지금 보는 폴더.
- 저장·동기화 구조는 그대로입니다. 이름·주소 검색 함수(searchBookmarks)를 bookmarks.js에 추가하고 테스트했습니다.

[13. 통계 (#70 → #74 → #77)]
- 처음에는 PC 바탕화면의 전용 통계 앱(#70)으로 만들었고, 폰에는 마이페이지 카드(#74)로 넣었다가, 최종적으로 가계부 화면 맨 아래(자산 카드 아래)의 📊 통계 카드 하나로 합쳤습니다(#77). PC 통계 앱 창·아이콘·시작 메뉴 항목은 없어졌고 마이페이지의 통계 카드도 없어졌습니다.

- PC에서는 카드 안에서 요약 4칸·그래프/표 2열로 넓게, 폰에서는 한 줄씩 쌓습니다. 클래식 스킨용 색도 따로 있습니다.

[14. 바탕화면 스킨을 폰 크기에 맞춤 (#75, #76, #77)]
- 🖥️ 단추의 [윈도우 98 → 바탕화면 → 클래식] 순서가 폰에서도 적용됩니다. 기본값은 윈도우 98 그대로입니다.
- 창: 열린 앱은 화면 전체 크기의 창(입체 테두리 틀 + 제목 막대 + 내용). _ ✕ 단추가 있고 최대화 단추는 없습니다. #76에서 요약 막대·창·작업표시줄 사이에 간격을 넣었습니다.
- 바탕화면(창을 최소화·닫거나 작업표시줄의 창 버튼을 누르면): 앱 아이콘 3열 2줄 + 오늘·가계부·달성/구독 위젯이 세로로 쌓입니다. 위젯의 할 일·루틴은 폰에서도 체크됩니다.
- 맨 위 요약 막대(한 줄로 흘러감), 아래 작업표시줄(시작·열린 창 버튼·시계). 아래 탭 바와 헤더는 없어지고, 알림·검색·테마는 시작 메뉴로 옮겼습니다.
- 폰에는 메모·북마크 전용 창이 없어서 아이콘을 누르면 마이페이지의 해당 카드를 펼쳐 보여 줍니다.
- 앱을 처음 열 때 달력 대신 홈(바탕화면)이 먼저 나옵니다(#77). PC·폰의 바탕화면 스킨 모두 해당하고, 윈도우 98·클래식 스킨은 이전처럼 달력으로 시작합니다. 🖥️ 단추로 스킨을 직접 바꿀 때는 보던 화면이 그대로 열립니다.
- 폰에서 앱 사이를 옮기려면 바탕화면이나 시작 메뉴를 거쳐야 합니다(탭 바 없음).

[15. 폰(윈도우 98·클래식)에도 적용한 PC 기능 (#74)]
- 메모 카드: 각 메모에 📌 고정 단추, 고정 우선·최근 수정순 정렬(PC 메모장과 같음), 메모가 3개 이상이면 검색창. 폰에서 고정한 메모는 PC 메모장에도 고정으로 보입니다.

[18. 둥근 모서리 윈도우 98 디자인 + 간격 줄이기 (#61)]

■ APK 받고 설치하는 방법
------------------------------------------------------------

1. 안드로이드 코드를 바꾼 PR(또는 푸시)의 GitHub Actions 실행 페이지에서 맨 아래 Artifacts → todo-widget-debug-apk 를 받습니다. (GitHub 로그인 필요, 약 3개월 보관)
2. main에 병합할 때는 APK가 자동으로 새로 만들어지지 않습니다. 새 APK가 필요하면 PR 빌드 결과를 받으세요.
3. 이 APK는 CI 서버가 만든 디버그 빌드라 만들 때마다 서명이 달라, 기존 앱 위에 덮어쓰기가 안 되면 기존 앱을 지우고 설치해야 합니다. 일정과 북마크는 서버에 있어 사라지지 않습니다.
4. 설치 후 홈 화면의 기존 위젯은 지우고 새로 올립니다.

한계
- 개발 환경에서는 외부망이 없어 북마크 사이트 아이콘 표시와 실제 서버 동기화를 직접 돌려 보지 못했고, 병합 로직 테스트로만 확인했습니다. (샘플 데이터로 화면을 확인했습니다.)
- 둥근 창 반지름 20dp는 갤럭시 기본 모서리를 스크린샷으로 어림해 정한 값입니다. 런처나 기기에 따라 더 크게 자르면 맨 끝부분이 조금 잘릴 수 있습니다.
- 위젯을 크게 키웠을 때의 달력 모드 간격은 손대지 않았습니다.
- 안드로이드 앱 본체 화면과 위젯에서 여는 일정 상세 팝업은 윈도우 98 디자인을 적용하지 않았습니다.
- 북마크 제목 자동 가져오기, 위젯에서의 링크 저장·폴더 관리는 없습니다.
- 가계부 날짜별 달력의 지출에는 구독 결제가 들어가지만, 아래 가계부 카드의 월 합계에는 들어가지 않습니다(구독이 있는 달은 숫자가 다르게 보일 수 있음).
- 바탕화면 스킨: 사진에 있던 메뉴 줄(파일/도움말), 도구 버튼 줄, 주소창은 눌러도 동작하지 않는 장식이 될 것 같아 넣지 않았고, 창을 끌어 옮기거나 크기를 바꾸는 기능도 없습니다. 요약 막대의 달성률은 반복 일정을 풀지 않은 원본 일정 기준이라 기존 달성률 표시와 같은 기준입니다.
- #78~#129 는 다른 세션에서 만든 것이라 이 문서는 커밋 기록만 읽고 쓴 것입니다. 실제 동작은 확인하지 못했고, 이후 수정으로 달라진 부분이 있을 수 있습니다.
- 가계부 이전 내역 삭제(#119)는 승인하면 실제로 지워지므로, 승인 전에 백업 파일이 내려받아졌는지 확인하시길 권합니다.
- PC 가계부 창은 아래쪽에 약 110px의 회색 빈 줄이 남습니다(기존 레이아웃의 아래 여백이며 이번 변경 때문이 아님).
- 폰은 실제 기기가 아니라 폰 크기(390×844) 브라우저로만 확인했습니다. 폰 바탕화면 스킨은 아이콘 크기·위젯 간격·작업표시줄 높이가 기기에 따라 어색할 수 있습니다.
- 메모·북마크의 PC 전용 창은 폰에서 쓰지 않습니다(폰은 마이페이지 카드). 폰에서 같은 메모를 두 기기가 동시에 고치면 마지막에 저장한 쪽이 남습니다.
- 요약 막대가 막대보다 길어지는 좁은 PC 화면(약 1000px 이하)이나 구독이 많은 날에는 글이 흘러갑니다.
