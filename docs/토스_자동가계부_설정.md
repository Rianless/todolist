# 토스 결제 → 하루 가계부 자동 입력 (안드로이드)

## 1. 서버 설정 (Vercel)
환경변수 `LEDGER_TOKEN` 에 길고 랜덤한 문자열을 넣고 다시 배포합니다.

## 2. 폰 설정 (MacroDroid 기준, Tasker도 같은 원리)
1. 토스 앱 알림 접근 허용: 설정 → 알림 → 기기 및 앱 알림 → MacroDroid 허용
2. 매크로 만들기
   - 트리거: **알림 수신** → 앱: 토스(토스뱅크), 내용에 `원` 포함
   - 동작: **HTTP 요청**
     - 방식 POST, 주소 `https://<내 앱 주소>/api/ledger`
     - 헤더 `x-ledger-token: <LEDGER_TOKEN 값>`, `Content-Type: application/json`
     - 본문 `{"text":"[notification_title] [notification]"}`
3. 토스에서 결제하고 앱 가계부에 뜨는지 확인

## 동작 규칙
- 결제/출금 → 지출, 입금 → 수입. 금액·가맹점은 알림 문구에서 추출, 가맹점 이름으로 카테고리 자동 분류(`api/_ledgerParse.js` 의 RULES 에서 수정)
- 취소/환불 알림, 가계부와 무관한 알림은 무시(직접 정리)
- 5분 안에 같은 알림이 중복 오면 한 번만 기록
- 자동 입력 항목은 메모가 `자동입력(토스)` 로 표시되고 `auto: true` 가 붙음

## 테스트
```bash
curl -X POST https://<내 앱 주소>/api/ledger -H 'x-ledger-token: <토큰>' -H 'Content-Type: application/json' -d '{"text":"스타벅스에서 4,500원 결제했어요"}'
```

## 지출 알림 → 물어보고 → 대충 적으면 가계부에 기록 (간편입력)
삼성 "모드 및 루틴"만으로는 글자 입력창과 HTTP 요청을 못 하므로 MacroDroid(또는 Tasker)를 같이 씁니다.

매크로 구성 (MacroDroid):
1. 트리거: **알림 수신** → 카드/은행/페이 앱 선택, 내용에 `원` 포함
2. 동작 ① **텍스트 입력 대화상자**(사용자 입력 요청): 제목 `어디에 썼어요?`, 결과를 변수 `memo` 에 저장
3. 동작 ② **HTTP 요청** POST `https://<내 앱 주소>/api/ledger`
   - 헤더 `x-ledger-token: <LEDGER_TOKEN 값>`, `Content-Type: application/json`
   - 본문 `{"quick":"{lv=memo}"}`
   - 알림에 금액이 이미 있으면 본문을 `{"quick":"{lv=memo} [notification]"}` 처럼 알림 문구를 붙이거나, 입력 때 금액을 같이 적으세요.

입력 예: `올리브영 만원` · `스벅 4500` · `택시 1만2천원` · `올리브영에서 1.5만원 썼어` · `용돈 5만원 받음`
- 금액 표현: 숫자, `만/천/백` 단위, 소수(1.5만) 지원. `용돈·월급·입금·받음` 이 있으면 수입, 아니면 지출
- 카테고리는 가게 이름으로 자동 분류(`api/_ledgerParse.js` 의 QUICK_RULES), 못 맞추면 `기타`
- 메모는 `간편입력(폰)` 으로 기록됩니다.

## 위젯 앱의 "결제 알림 간편입력" (화면 전환 없이 알림 칸에서 바로 입력)
위젯 앱(`android-widget`) 2.7.0 부터 들어 있는 기능입니다. 토스 결제 알림이 오면 화면 위에 "💰 어디에 썼어요?" 알림이 내려오고, 그 알림의 입력칸에 `올리브영 만원` 처럼 적어 보내면 `/api/ledger` 의 `quick` 입력으로 전송돼 가계부에 저장됩니다. 이름만(`올리브영`) 적으면 알림에 있던 금액을 붙여서 보냅니다.

설치·설정 (폰):
1. 새 APK 를 설치합니다 (기존 위젯 앱 위에 덮어 설치).
2. 앱 오른쪽 위 ⋮ → **결제 알림 간편입력 설정**
3. 가계부 비밀번호(Vercel 의 `LEDGER_TOKEN` 값)를 입력하고 **저장**
4. **① 알림 읽기 허용 열기** → 이 앱을 켜기, **② 알림 표시 허용**
5. **③ 테스트 알림 보내기** 로 입력칸 알림이 뜨는지 확인

참고:
- 감시하는 앱은 기본이 토스(`viva.republica.toss`)입니다. 다른 카드·은행 앱은 설정 화면의 "감시할 앱 이름"에 패키지 이름을 쉼표로 더합니다.
- 갤럭시 루틴으로 `?quick=1` 을 여는 방식과 같이 쓰면 입력창이 두 번 뜨니, 이 기능을 쓸 때는 그 루틴을 끄세요.
- 비밀번호는 이 앱 안에만 저장됩니다(SharedPreferences).
