# 회사 스킨

앱의 기능을 회사 부서로 보여 주는 화면입니다. 기능과 데이터는 그대로이고 보여 주는 방식만 다릅니다.

## 켜기
헤더의 🖥️ 버튼을 누르면 화면 스타일이 `윈도우 98 → 바탕화면 → 클래식 → 회사` 순서로 바뀝니다.
회사 화면 위쪽의 🖥️ 로도 바꿀 수 있고, 고른 스타일은 기기에 저장됩니다.

## 부서
부서를 누르면 그 기능이 열리고, 왼쪽 아래 「🏢 로비로」로 돌아옵니다.

| 층 | 부서 | 기능 |
|---|---|---|
| 3F | 비서실 / 기획실 / 대표실 | 일정 / D-day / 다이어리 |
| 2F | 회계부 / 재무팀 / 구독관리팀 / 통계실 | 가계부 / 자산 / 구독 / 통계 |
| 1F | 물류팀 / 자료실 / 메모실 / 미디어팀 / 총무팀 | 택배 / 북마크 / 메모 / SaveTube / 설정 |

부서 이름과 구성은 `js/office.js` 의 `OF_FLOORS` 에서 바꿉니다.

## 지하 서버실
- **앱 동작**: 앱이 `/api` (일정·가계부 저장, 불러오기)를 부를 때마다 서버랙이 깜빡이고 기록이 남습니다.
- **Claude Code 작업**: 내 PC 에서 이 폴더로 `claude` 를 쓰면 코딩하는 모습이 보입니다.
  새 파일 작성(📦 상자가 올라옴) · 코드 수정 · 테스트 실행 · 명령 실행 · git · 파일 확인.

### Claude Code 작업 연결
```
npm run office-bridge
```
그다음 서버실의 「🔌 Claude 작업 연결」을 켭니다 (켜 둔 사람의 브라우저만 내 PC 에 접속합니다).

- 브리지는 `127.0.0.1` 에서만 열리고, 허용된 주소(배포 주소, localhost)에서 온 요청만 받습니다.
  다른 주소에서 쓰려면 `OFFICE_ORIGINS=https://내주소` 로 추가합니다.
- 이 폴더의 Claude Code 기록(`~/.claude/projects/<이 폴더>`)만 읽고, **활동 종류와 이 폴더 기준 파일 경로만** 내보냅니다.
  프롬프트, 답변, 명령어 원문은 보내지 않습니다.
- 브리지를 켠 뒤에 일어난 일만 보입니다. 브라우저에서 연결이 안 되면 브라우저의 로컬 네트워크 접근 허용 질문에 허용해 주세요.

별도 뷰어 [claude-office](claude-office.md) 와는 독립이라 둘을 같이 써도 됩니다.
