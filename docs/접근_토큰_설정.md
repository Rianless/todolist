# 서버 접근 토큰(APP_TOKEN) 설정

저장소가 공개라서 배포 주소가 코드에 드러나 있습니다. `/api/state`, `/api/todos` 는 토큰이 있어야만 열리도록 막을 수 있습니다.
**`APP_TOKEN` 환경변수를 설정하기 전까지는 예전처럼 누구나 접근됩니다.** 아래 순서대로 하세요.

## 순서 (중요: 서버 설정은 맨 마지막)
1. **토큰 만들기** — 길고 랜덤한 문자열 (예: `openssl rand -hex 24`)
2. **안드로이드 위젯**: GitHub 저장소 → Settings → Secrets and variables → Actions → New repository secret
   이름 `APP_TOKEN`, 값 = 위 토큰. 그다음 Actions 에서 "Build widget APK" 를 다시 실행해 새 APK 를 받아 설치.
3. **데스크톱 위젯**: 환경변수 `TODOLIST_TOKEN` 에 토큰을 넣거나, 설정 폴더(`app.getPath('userData')`)에 `app-token.txt` 파일을 만들어 토큰 한 줄을 적음.
4. **웹앱(폰·PC 브라우저)**: 따로 할 일 없음. 서버가 막으면 처음 한 번 비밀번호를 물어보고 그 기기에 저장.
5. **마지막으로** Vercel → Settings → Environment Variables 에 `APP_TOKEN` = 같은 토큰을 넣고 Redeploy.

## 확인
토큰 없이 `https://<내 주소>/api/state` 를 열면 `{"error":"unauthorized"}` 가 나와야 합니다.

## 참고
- 토큰이 바뀌면 모든 기기에서 다시 입력/빌드해야 합니다.
- `/api/ledger` 는 별개의 토큰(`LEDGER_TOKEN`)을 씁니다.
