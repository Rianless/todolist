# 나의 하루 - PC 위젯 (Windows)

웹앱, 안드로이드 위젯과 **같은 서버 데이터**를 보여주는 PC용 위젯입니다.

```
웹앱 ──┐
폰 위젯 ─┼── 같은 서버 (/api/todos, /api/state)
PC 위젯 ─┘
```

- 일정: `/api/todos` (반복 일정 포함, 웹앱과 같은 규칙)
- 가계부, 구독: `/api/state` (구독 결제일도 웹앱과 같은 규칙)
- 1분마다, 그리고 위젯을 클릭해 활성화할 때마다 자동으로 새로고침합니다.
- **일정은 위젯에서 추가·수정·삭제·완료 체크를 할 수 있습니다.**
  - `+ 일정` 버튼: 새 일정 추가 (선택한 날짜가 기본값)
  - 일정 줄을 누르면: 수정 창 (삭제는 버튼을 두 번 눌러야 지워집니다)
  - 일정 줄 오른쪽 원을 누르면: 완료 / 완료 취소
  - 제목을 숨긴(비공개) 일정은 위젯에서 완료 체크만 할 수 있습니다.
- 창을 충분히 키우면(가로 480px, 세로 700px 이상) 주 줄 대신 **달력 모드**(한 달 칸)로 바뀌고, 다시 줄이면 주 줄로 돌아옵니다. 달 이동은 ‹ ›, 날짜를 누르면 아래에 그날 일정이 나옵니다.
- 일정 순서는 웹앱과 같습니다. 일정 줄 왼쪽 손잡이(⋮⋮)를 끌거나(또는 손잡이에서 방향키 ↑↓) 순서를 바꾸면 서버(`/api/state`의 `itemOrder`)에 저장되어 웹앱·폰 위젯에도 같은 순서로 보입니다. 저장할 때는 최신 상태를 읽어 `itemOrder`만 바꿔 다시 쓰므로 가계부 등 다른 내용은 그대로입니다.
- 가계부와 구독은 보기 전용입니다. 추가·수정은 웹앱에서 하세요. (`웹앱 열기` 버튼)
- 일정은 서버의 `/api/todos` 표에 **한 줄씩만** 저장합니다. 웹앱의 다른 데이터(가계부, 구독 등)는 건드리지 않습니다.
- 웹앱을 오래 열어 둔 탭이 있으면 위젯에서 바꾼 내용이 보이지 않을 수 있으니 새로고침하세요. 그 탭에서 저장하면 옛 내용으로 되돌아갈 수 있습니다.

## 사용법

- 창 위쪽 바를 끌어서 옮기고, 가장자리를 끌어서 크기를 바꿉니다. 위치와 크기는 기억합니다.
- `✕`는 종료가 아니라 **트레이로 숨기기**입니다. 완전히 끄려면 트레이 아이콘 우클릭 → 종료.
- 트레이 아이콘 우클릭 메뉴: 열기 / 웹앱 열기 / 항상 위에 표시 / Windows 시작 시 자동 실행 / 종료
- **처음 실행하면 Windows 시작 시 자동 실행이 켜집니다.** PC를 껐다 켜면 위젯이 저절로 나타납니다. 끄려면 트레이 메뉴에서 체크를 해제하세요.
- exe 파일을 다른 폴더로 옮기면 자동 실행이 끊기므로, 옮긴 뒤에는 한 번 실행해서 트레이 메뉴의 체크를 껐다 켜 주세요.
- 부팅 직후 네트워크가 아직 안 잡혀 있으면 15초마다 다시 시도합니다.
- 📌 버튼으로도 '항상 위에 표시'를 켜고 끌 수 있습니다.

## 개발

```
cd desktop-widget
npm install
npm start        # 위젯 실행
npm test         # 계산 로직이 웹앱(index.html)과 같은지 검사
npm run dist     # Windows용 exe 만들기 (dist/ 폴더)
```

서버 주소는 기본값(`https://todolist-liart-mu.vercel.app`)을 쓰며, 환경변수 `TODOLIST_URL`로 바꿀 수 있습니다.

GitHub에서는 `desktop-widget/` 을 고쳐 push 하면 Actions(`Build PC widget`)가 exe를 만들어 Artifacts 로 올려줍니다.
